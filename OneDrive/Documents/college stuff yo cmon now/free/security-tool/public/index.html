    Common problems
    
            
    
              Exact page not found
              
    Try sporcle.com instead of sporcle.com/games/pokemon/151.
    
            
    
            
    
              Quota warning
              
    Wait one minute. Public VirusTotal allows 4 lookups per minute.
    
            
    
            
    
              File hash confusion
              
    Hash text, not the file itself.
